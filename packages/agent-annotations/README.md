# agent-annotations

Init scaffold for Agent Annotations.

## Usage

```bash
pnpm dlx agent-annotations init
```

### Common options

- `--agent auto|codex|claude|gemini|antigravity|opencode|copilot|all`
- `--skill repo|user|none`
- `--receiver repo|none`
- `--force`
